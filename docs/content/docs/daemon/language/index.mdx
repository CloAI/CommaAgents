# Language Services

`createTypeScriptLanguageService` provides the language operations exposed to daemon-run tools for TypeScript and JavaScript workspaces.

```ts
import { createTypeScriptLanguageService } from "@comma-agents/daemon";

const service = createTypeScriptLanguageService({
  workspaceRoot: process.cwd(),
});

const result = await service.request({
  method: "textDocument/diagnostic",
  languageId: "typescript",
  path: "src/index.ts",
});
```

The service uses the workspace's `tsconfig.json` when present and otherwise builds an inferred project. It supports diagnostics, hover information, definitions, type definitions, implementations, references, document symbols, and workspace symbols.
