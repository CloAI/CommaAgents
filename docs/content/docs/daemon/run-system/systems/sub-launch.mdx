# Sub-launch System

The sub-launch system provides the strategy-launch capability used by agents. A nested strategy inherits the parent run's cancellation boundary, sandbox, interaction services, and skills while receiving its own run identifier and MCP connections.

Installed projects that execute code must be approved before the daemon loads them. See [Strategy projects](/docs/core/strategy/projects) for project manifests and permissions.
