# MCP Runtime

The run-system MCP module combines global, workspace, strategy, and persisted run choices into the effective server set used for preparation. Each prepared run receives its own connections and agent tool assignments.

Clients normally manage this module through [`list_mcp_servers` and `update_mcp_server`](/docs/daemon/server/protocol/mcp). Embedded hosts use `RunSystem.listMcpServers()` and `RunSystem.updateMcpServer()`.

## RunMcpServerStatus

The safe server status returned to clients. Credentials, headers, and environment values are not included.

## Resolution behavior

Server definitions are discovered through Core's MCP configuration rules. The daemon applies the saved enabled-server selection for a run, connects enabled servers during preparation, and reports failures without rejecting the entire preparation.

Run-scoped changes apply to the next preparation or continuation. They do not replace tools during an active agent call.
