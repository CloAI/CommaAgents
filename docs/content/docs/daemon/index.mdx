# Daemon

`@comma-agents/daemon` runs strategies in a long-lived process. Its plugins own execution, persistence, interactive requests, providers, and projects. Use the CLI for a managed process:

```bash
comma daemon start
comma daemon status
```

For an embedded host, create a kernel and attach its server:

```ts
import { createDaemonKernel, createDaemonServer } from "@comma-agents/daemon";

const daemon = await createDaemonKernel({ runs: { runsDir: "./runs" } });
const server = createDaemonServer({ daemon, host: "127.0.0.1", port: 7422 });
try {
  await server.start();
  console.log(server.url);
  // Run the host until shutdown is requested.
} finally {
  await server.stop();
  await daemon.dispose();
}
```
