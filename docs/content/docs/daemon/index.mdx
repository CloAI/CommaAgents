# Daemon

`@comma-agents/daemon` runs Comma Agents strategies in a long-lived process. It exposes a WebSocket server for clients, persists run timelines, manages interactive requests, and provides APIs for starting or embedding the daemon.

For normal use, start the managed daemon through the CLI:

```bash
comma daemon start
comma daemon status
```

Embed the server when another application owns the process lifecycle:

```ts
import {
  createDaemon,
  initializeLogging,
  loadDaemonConfig,
} from "@comma-agents/daemon";

const config = loadDaemonConfig();
const logging = initializeLogging({
  level: config.logLevel,
  file: config.logFile,
});
const daemon = createDaemon({ config });

await daemon.start();
console.log(daemon.url);

// When the application is ready to shut down:
try {
  await daemon.stop();
} finally {
  logging.close();
}
```
