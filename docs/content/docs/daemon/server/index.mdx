# Server

Use `createDaemonKernel` to construct the daemon's plugins and `createDaemonServer` to expose their registered commands and channels. The CLI starts this same kernel and server.

See [Plugin server](/docs/daemon/server/plugin-server) for embedding, lifecycle, and message envelopes; [Runs API](/docs/daemon/server/runs) for execution; and [Protocol](/docs/daemon/server/protocol) for client examples.
