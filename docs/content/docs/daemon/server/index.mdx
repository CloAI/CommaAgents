# Server

The daemon is a WebSocket server that hosts strategy runs and communicates with clients through the typed protocol. Use `createDaemon` when embedding the server, or the [CLI](/docs/daemon/cli) to run it as a managed process.

```ts
import {
  createDaemon,
  initializeLogging,
  loadDaemonConfig,
} from "@comma-agents/daemon";

const config = loadDaemonConfig();
const logging = initializeLogging({ level: config.logLevel, file: config.logFile });
const daemon = createDaemon({ config });

await daemon.start();
console.log(daemon.url);

// When the application is ready to shut down:
try {
  await daemon.stop();
} finally {
  logging.close();
}
```

## Connecting clients

After `start()` resolves, use `daemon.url` as the WebSocket endpoint. The server also exposes `GET /health` on the same host and port. See the [protocol overview](/docs/daemon/server/protocol) for connection and message details.
