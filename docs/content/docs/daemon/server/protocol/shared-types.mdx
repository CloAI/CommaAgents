# Shared Types

These JSON shapes are reused by multiple daemon protocol messages.

## Usage

| Field | Type | Description |
|---|---|---|
| `promptTokens` | `number` | Tokens supplied to the model |
| `completionTokens` | `number` | Tokens generated by the model |

## ContextUsageWire

Token occupancy for the final model step.

| Field | Type | Description |
|---|---|---|
| `totalTokens` | `number` | Total tokens occupying the context |
| `inputTokens` | `number?` | Input token count when reported |
| `outputTokens` | `number?` | Output token count when reported |
| `inputTokenDetails` | `object?` | Optional no-cache, cache-read, and cache-write counts |
| `outputTokenDetails` | `object?` | Optional text and reasoning token counts |

## AgentCallResultWire

| Field | Type | Description |
|---|---|---|
| `text` | `string` | Final text result |
| `usage` | [`Usage`](#usage) | Prompt and completion usage |
| `contextUsage` | [`ContextUsageWire?`](#contextusagewire) | Final-step context occupancy |
| `finishReason` | `string` | Model finish reason |

## ErrorInfo

| Field | Type | Description |
|---|---|---|
| `code` | `string` | Machine-readable execution error code |
| `message` | `string` | Human-readable error message |

## RunSummary

The in-memory run summary returned by `strategy_list`.

| Field | Type | Description |
|---|---|---|
| `runId` | `string` | Stable run identifier |
| `strategyName` | `string` | Display name of the strategy |
| `status` | `pending \| running \| completed \| error \| cancelled` | Current lifecycle status |
| `startedAt` | `string` | ISO-8601 start timestamp |
| `completedAt` | `string?` | ISO-8601 terminal timestamp |

## ConversationRecordWire

| Field | Type | Description |
|---|---|---|
| `id` | `string` | Stable record identifier |
| `agentName` | `string` | Agent that produced the record |
| `createdAt` | `string` | ISO-8601 creation timestamp |
| `userMessage` | `object` | Structured user-role message |
| `responseMessages` | `object[]` | Structured assistant and tool messages |
| `text` | `string` | Final response text |
| `usage` | [`Usage`](#usage) | Token usage |
| `contextUsage` | [`ContextUsageWire?`](#contextusagewire) | Final-step context occupancy |
| `finishReason` | `string` | Model finish reason |
| `status` | `active \| superseded` | Retention state when present |
| `supersededBy` | `string?` | Replacement record identifier |

## ConversationRetentionEventWire

A compaction event identifies the affected agent and records, why compaction occurred, the trigger measurements, the summary record, and the records retained or superseded.

| Field | Type | Description |
|---|---|---|
| `id` | `string` | Stable retention event identifier |
| `agentName` | `string` | Agent whose conversation was compacted |
| `createdAt` | `string` | ISO-8601 event timestamp |
| `kind` | `"compaction"` | Retention event kind |
| `reason` | `"context-window" \| "record-count"` | Condition that initiated compaction |
| `trigger` | `object` | Available model, token, ratio, and record-count measurements |
| `recordsCompacted` | `number` | Number of records summarized |
| `recordsRetained` | `number` | Number of original records kept active |
| `summaryRecord` | [`ConversationRecordWire`](#conversationrecordwire) | Replacement summary record |
| `supersededRecordIds` | `string[]` | Records replaced by the summary |
| `insertBeforeRecordId` | `string?` | Record before which the summary is inserted |

## ConversationHistoryWire

| Field | Type | Description |
|---|---|---|
| `records` | [`ConversationRecordWire[]`](#conversationrecordwire) | Agent-call records in display order |
| `retentionEvents` | [`ConversationRetentionEventWire[]`](#conversationretentioneventwire) | Applied compaction events |
| `inputs` | `{ text, beforeRecordId? }[]` | Human inputs and their transcript positions |

## AgentStreamEventWire

The stream-event union contains `retention`, `text`, `tool-call`, `tool-result`, `thinking-start`, `thinking`, `thinking-end`, `step-start`, and `done`. See [Strategy observation](/docs/daemon/server/protocol/strategy-observation#stream-event-types) for fields and examples.
