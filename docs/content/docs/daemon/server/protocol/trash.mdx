# Trash

The trash protocol manages files moved to recoverable workspace trash by file tools.

## List entries

```json
{ "type": "trash_list", "cwd": "/workspace", "requestId": "trash-1" }
```

`cwd` is optional and defaults to the daemon working directory. The `trash_list_result` response contains workspace groups, entry metadata, `totalEntries`, and `totalBytes`.

Each entry includes its trash path, byte size, original path, original SHA-256 hash, trash timestamp, and optional run, session, or agent identifiers.

## Restore an entry

```json
{
  "type": "trash_restore",
  "cwd": "/workspace",
  "trashPath": "/workspace/.comma/trash/entry",
  "targetPath": "/workspace/src/restored.ts",
  "requestId": "trash-2"
}
```

`cwd` and `trashPath` are required. `targetPath` is optional. Success returns `trash_restore_result` with `restored` and `from`; failure returns `RESTORE_FAILED`.

## Clear entries

```json
{ "type": "trash_clear", "cwd": "/workspace", "requestId": "trash-3" }
```

The `trash_clear_result` response reports `cleared` and `bytesFreed`.
