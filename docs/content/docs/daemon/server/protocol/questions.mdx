# Questions

When a tool needs explicit user feedback, the daemon broadcasts `request_question` to run subscribers. A client returns the answer with `question_response`.

## Event: `request_question`

```json
{
  "type": "request_question",
  "runId": "run_abc123",
  "requestId": "question-uuid",
  "agentName": "planner",
  "toolName": "ask_question",
  "question": "Which deployment target should I use?",
  "ts": "2026-07-04T12:00:00.000Z"
}
```

| Field | Type | Description |
|---|---|---|
| `type` | `"request_question"` | Message discriminator |
| `runId` | `string` | Run waiting for an answer |
| `requestId` | `string` | Unique question ID copied into `questionRequestId` |
| `agentName` | `string` | Agent that requested the answer |
| `toolName` | `string` | Tool that asked the question |
| `question` | `string` | Question shown to the user |
| `ts` | `string` | ISO-8601 timestamp |

## Request: `question_response`

```json
{
  "type": "question_response",
  "runId": "run_abc123",
  "questionRequestId": "question-uuid",
  "response": "Deploy to staging first",
  "requestId": "client-correlation-id"
}
```

| Field | Type | Required | Description |
|---|---|---|---|
| `type` | `"question_response"` | yes | Message discriminator |
| `runId` | `string` | yes | Run waiting for the answer |
| `questionRequestId` | `string` | yes | `requestId` from `request_question` |
| `response` | `string` | yes | User's answer |
| `requestId` | `string` | no | Correlation ID echoed on errors |

Success has no direct reply. If the question is no longer pending, the daemon returns `error` with code `NO_PENDING_QUESTION`.
