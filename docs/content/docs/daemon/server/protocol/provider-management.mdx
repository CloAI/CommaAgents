# Provider Management

Provider registration makes a known catalog provider available to runtime model resolution. Registration is persisted across daemon restarts.

## Register a provider

```json
{
  "type": "register_provider",
  "providerId": "openai",
  "requestId": "provider-1"
}
```

The daemon replies with `provider_registered` containing `providerId`. Re-registering an existing provider succeeds without creating a duplicate. An unknown provider returns `NOT_FOUND`.

## Unregister a provider

```json
{
  "type": "unregister_provider",
  "providerId": "openai",
  "requestId": "provider-2"
}
```

The daemon replies with `provider_unregistered`. Removing an ID that is not registered also succeeds.

## Credentials

`set_credential` stores one global credential for a provider. Use the payload field that matches `credentialType`.

```json
{
  "type": "set_credential",
  "providerId": "openai",
  "credentialType": "api",
  "apiKey": "secret",
  "requestId": "credential-1"
}
```

| Field | Type | Required | Description |
|---|---|---|---|
| `type` | `"set_credential"` | yes | Message discriminator |
| `providerId` | `string` | yes | Provider receiving the credential |
| `credentialType` | `"api" \| "oauth" \| "custom"` | yes | Credential shape to store |
| `apiKey` | `string` | for `api` | API key value |
| `oauthToken` | `string` | for `oauth` | OAuth access token |
| `customData` | `Record<string, unknown>` | no | Provider-specific custom fields |
| `requestId` | `string` | no | Correlation ID echoed by the response |

Success returns `credential_set` with `providerId` and `credentialType`. Credential values are never returned by the protocol.
