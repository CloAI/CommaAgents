# Protocol

Connect to `/ws` and send a command or subscription with a UUIDv4 request ID. Import validation schemas and inferred command/channel types from `@comma-agents/daemon/protocol`.

```ts
import { ServerMessageSchema } from "@comma-agents/daemon/protocol";

const socket = new WebSocket("ws://127.0.0.1:7422/ws");
socket.addEventListener("open", () => {
  socket.send(
    JSON.stringify({
      type: "command",
      requestId: crypto.randomUUID(),
      command: "status.get",
      arguments: {},
    }),
  );
});
socket.addEventListener("message", ({ data }) => {
  const message = ServerMessageSchema.safeParse(JSON.parse(String(data)));
  if (message.success) console.log(message.data);
});
```

Commands return a response with the same request ID. Subscriptions receive their registered channel's domain events until unsubscribed or disconnected. See [Plugin server](/docs/daemon/server/plugin-server) for envelopes and errors, [Runs API](/docs/daemon/server/runs) for execution and history, and [Projects protocol](/docs/daemon/server/protocol/projects) for workspace organization.
