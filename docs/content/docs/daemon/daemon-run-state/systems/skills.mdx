# Skills System

The skills system loads the effective skill registry for the run working directory. Workspace-local skills take precedence over global skills with the same name, and invalid skill sources are reported as daemon warnings without stopping unrelated skills from loading.

See [Core skills](/docs/core/skills) for discovery locations and the agent-facing skill tools.
