# MCP System

The MCP system resolves enabled servers during preparation, opens the run's connections, assigns discovered tools to configured agents, and closes the connections during cleanup.

Connection outcomes are returned in `run_prepared.mcpServers`. See [MCP runtime](/docs/daemon/daemon-run-state/mcp) for configuration behavior and [MCP protocol](/docs/daemon/server/protocol/mcp) for client operations.
