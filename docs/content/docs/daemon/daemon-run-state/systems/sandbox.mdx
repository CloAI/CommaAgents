# Sandbox System

The sandbox system creates the filesystem and command boundary used by tools in a run. Its root is the run working directory, and authorization requests are handled by the run's permission system.

See [Core sandbox](/docs/core/sandbox) for policy configuration and [Sandbox permissions](/docs/daemon/server/protocol/sandbox-permissions) for interactive decisions.
