# Daemon Module

The daemon module groups process lifecycle APIs, foreground runtime helpers, and shared command handlers.

```ts
import {
  getDaemonProcessStatus,
  startDaemonProcess,
  stopDaemonProcess,
} from "@comma-agents/daemon";

const started = await startDaemonProcess({ allowExisting: true });
console.log(started.message);

const status = getDaemonProcessStatus();
console.log(status.state, status.pid);

await stopDaemonProcess();
```

Use the process APIs when an application needs to start, stop, restart, or inspect the managed daemon. Use `createDaemonKernel` and `createDaemonServer` when another host owns the [server lifecycle](/docs/daemon/server/plugin-server).
