# comma CLI

The `comma` command is the primary entrypoint for CommaAgents. It launches the TUI, starts the daemon when needed, manages daemon autostart, and validates the local installation.

## Install

Install from npm:

```bash
pnpm add --global @comma-agents/cli@next
comma install
```

The npm package requires Node.js 26 or newer. It installs the TUI, daemon, and core as package dependencies; only the CLI needs to be installed globally.

With Node.js 26 and pnpm installed, run the platform bootstrap script for your operating system and it will install the CLI package before opening `comma install`.

```bash
curl -fsSL https://commaagents.com/install | bash
```

On Windows, run the PowerShell installer:

```powershell
iwr https://commaagents.com/install-win -useb | iex
```

## Launch The TUI

```bash
comma
```

`comma` checks the daemon first. If the daemon is not running, it starts it in the background, waits for readiness, and then opens the terminal UI.

You can pass the same launch options as the TUI:

```bash
comma --strategy Plan --input "Review this repo"
comma tui --daemon-url ws://127.0.0.1:7422/ws
```

## Run A Strategy Headlessly

`comma run` executes a strategy in the current process without the TUI or a running daemon. Use it for scripts, CI, and benchmarks.

```bash
comma run -s Build -i "Fix the failing parser test" --approve allow
comma run -s Plan -i "Add retry support to webfetch" --then Build --approve allow --json
```

| Option | Description |
|---|---|
| `-s, --strategy` | Strategy file path, name, or label. |
| `-i, --input` | First user message. |
| `--cwd` | Working directory for the run. Defaults to the current directory. |
| `-m, --model` | `provider/model` used by every agent, including subagents. |
| `--max-user-turns` | User turns accepted before the run stops. Defaults to 1. |
| `--approve allow\|deny` | Answer for every sandbox permission request. Defaults to `deny`. |
| `--then <strategy...>` | Switch to each strategy in order, in the same conversation, after the previous one finishes. |
| `--then-input` | Message sent to each `--then` strategy. |
| `--json` | Print the run ID, outcome, agent messages, and token usage as JSON. |

Questions an agent asks during the run are answered with an instruction to proceed with its recommended option. With `--json`, `endedBy` is `turn-limit` when the run stopped because `--max-user-turns` was used up after the work finished.

## Manage The Daemon

```bash
comma daemon start
comma daemon status
comma daemon status --json
comma daemon stop
comma daemon restart
```

Autostart is explicit. Run the installer or use these commands:

```bash
comma daemon enable
comma daemon disable
```

The autostart mechanism is user-level: launchd on macOS, systemd user services on Linux, and a Windows logon scheduled task on Windows.

## Check The Installation

```bash
comma doctor
comma doctor --json
```

Doctor checks runtime availability, daemon config, daemon state, writable data directory, autostart support, PATH visibility, and provider configuration files.

## Uninstall

Run the interactive uninstaller:

```bash
comma uninstall
```

The command stops the daemon, disables and removes daemon autostart, and removes the standalone executable or detected global package installation. It separately asks whether to remove conversation history, installed Hub and provider packages, and remaining configuration such as credentials, logs, trash, global skills, and strategies.

For non-interactive removal, pass `--yes` and the data categories to delete:

```bash
comma uninstall --yes --remove-history --remove-packages --remove-config
```

Data-removal flags default to false when `--yes` is used.
