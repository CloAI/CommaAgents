# Generation Options

`providerOptions` enables provider-specific features. `modelOptions` controls portable settings such as temperature, token limits, sampling, retry count, and seed. Both apply to every model call made by the agent.

```ts
import { createAgent } from "@comma-agents/core";

const planner = createAgent({
  name: "planner",
  model: "anthropic/claude-sonnet-4-5",
  providerOptions: {
    anthropic: {
      thinking: { type: "enabled", budgetTokens: 8_000 },
    },
  },
  modelOptions: {
    temperature: 0.2,
    maxOutputTokens: 4_096,
    maxRetries: 2,
  },
});
```

## Provider options

Use `providerOptions` only for settings defined by the selected provider. Keys are provider IDs, and each value contains that provider's settings.

```ts
const reasoningAgent = createAgent({
  name: "reasoning-agent",
  model: "openai/gpt-4o",
  providerOptions: {
    openai: { reasoningEffort: "high" },
  },
});
```
