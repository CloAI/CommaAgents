# createAgent

`createAgent` creates a stateful agent that you can call or stream. Use it for model-backed agents, or provide `execute` when the agent should run application code instead of a model.

```ts
import { createAgent } from "@comma-agents/core";

const agent = createAgent({
  name: "assistant",
  model: "openai/gpt-4o",
  systemPrompt: "You are a concise coding assistant.",
  tools: ["read_file", "grep", "edit_file"],
});

const result = await agent.call("Find and fix the failing parser test.");
console.log(result.text);
```

## Identity and model

Every agent has a stable `name`. Model-backed agents also specify the model used for each call.

```ts
const reviewer = createAgent({
  name: "pull-request-reviewer",
  model: "anthropic/claude-sonnet-4-5",
});
```

The name identifies the agent in flows, tool calls, logs, and conversation records. Give every agent in a workflow a unique, stable name.

`model` accepts an explicit `"providerID/modelID"` value or a bare model ID that the catalog can resolve. Explicit provider IDs make model selection deterministic when several providers expose the same model name.

```ts
const explicit = createAgent({
  name: "explicit-model",
  model: "openai/gpt-4o",
});

const catalogResolved = createAgent({
  name: "catalog-model",
  model: "gpt-4o",
});
```

Omit `model` only when using [custom execution](/docs/core/agents/create-agent/custom-execution). See [Model Resolution](/docs/core/model) for provider registration, credentials, and catalog lookup.

## System prompt

`systemPrompt` defines the instructions applied to each model call. Use a string for fixed instructions or a prompt template when values change while the agent remains the same.

```ts
const reviewer = createAgent({
  name: "reviewer",
  model: "openai/gpt-4o",
  systemPrompt: "Review TypeScript for correctness and maintainability.",
});
```

Templates provide default variables that can be updated before later calls.

```ts
import { createAgent, createPromptTemplate } from "@comma-agents/core";

const templatedReviewer = createAgent({
  name: "reviewer",
  model: "openai/gpt-4o",
  systemPrompt: createPromptTemplate({
    template: "Review {{ language }} as a {{ role }}.",
    variables: {
      language: "TypeScript",
      role: "maintainer",
    },
  }),
});

templatedReviewer.updatePromptVariables?.({ role: "security reviewer" });
await templatedReviewer.call("Review src/auth.ts.");
```

`updatePromptVariables()` merges new values into the template defaults. It has no effect when the agent uses a static string prompt. See [Prompts & Templates](/docs/core/prompts) for filters, variable sources, and reusable templates.

## Tools and maximum steps

`tools` lists the built-in or registered tool names available to an agent. Names are resolved when the agent runs, so custom tools must be registered before the first call.

```ts
import {
  createAgent,
  defineTool,
  okResult,
  registerTool,
} from "@comma-agents/core";
import { z } from "zod";

registerTool(
  "lookup_issue",
  defineTool({
    description: "Look up an issue by number.",
    parameters: z.object({ number: z.number().int().positive() }),
    execute: async ({ number }) =>
      okResult(`Issue #${number} is open.`, {
        data: { number, status: "open" },
      }),
  }),
);

const triage = createAgent({
  name: "triage",
  model: "openai/gpt-4o",
  tools: ["lookup_issue", "read_file", "grep"],
});
```

See [Tools](/docs/core/tools) for built-in tools and [registerTool](/docs/core/tools/tool-registry) for custom tools.

`maxSteps` limits the number of model steps in one call. A step can produce a final answer or request tools and continue. The default is `10`.

```ts
const investigator = createAgent({
  name: "investigator",
  model: "openai/gpt-4o",
  tools: ["grep", "read_file", "run_command"],
  maxSteps: 20,
});
```

Lower the limit for tightly bounded work. Raise it only when the workflow legitimately needs more tool rounds.
