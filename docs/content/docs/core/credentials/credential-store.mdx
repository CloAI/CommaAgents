# Credential store

The credential store is the central API for resolving, reading, and writing credentials. It combines a storage backend with environment variable lookups and strategy-scoped overrides.

## Creating a store

```ts
import {
  createCredentialStore,
  createJsonFileCredentialBackend,
  getCredentialsPath,
} from "@comma-agents/core";

const store = createCredentialStore({
  backend: createJsonFileCredentialBackend({ filePath: getCredentialsPath() }),
});
```

## Resolving credentials

`resolve` is the primary method — it walks the [resolution chain](/docs/core/credentials#resolution-chain) and returns the best credential for a provider:

```ts
// Check strategy scope → env vars → global scope
const cred = await store.resolve("openai", "my-strategy");

// Omit scope to skip strategy-scoped lookup
const cred = await store.resolve("openai");
```

Returns `undefined` if no credential is found in any layer.

## Reading and writing

Use `get`, `set`, and `remove` to work with credentials in a specific scope directly, bypassing the resolution chain:

```ts
// Store a global API key
await store.set("openai", "$global", { type: "api", key: "sk-..." });

// Store a strategy-specific key
await store.set("openai", "my-strategy", {
  type: "api",
  key: "sk-project-...",
});

// Read from a specific scope (no fallback)
const cred = await store.get("openai", "$global");

// Remove a credential
const removed = await store.remove("openai", "my-strategy"); // true if it existed
```

`set` and `remove` mutations are serialized within a credential-store instance so concurrent writes do not lose unrelated changes. A failed mutation does not prevent subsequent operations. This does not provide locking between processes.

## Credential source

Use `getSource` to inspect global credential resolution without reading the secret. It reports `"environment"`, `"global"`, or `"none"`; strategy-scoped lookup remains available through `resolve`.

```ts
const source = await store.getSource("openai");
```

## Listing credentials

```ts
// List provider IDs in a scope
const providers = await store.list("$global");
// ["openai", "anthropic"]

// List all scopes that have credentials
const scopes = await store.listScopes();
// ["$global", "my-strategy"]
```

## Global credential store

Core creates a default file-backed global store on first use. Override it when your project uses another backend or environment mapping:

```ts
import {
  setGlobalCredentialStore,
  getGlobalCredentialStore,
} from "@comma-agents/core";

// Override the default store for your application
setGlobalCredentialStore(store);

// Read anywhere in the application
const globalStore = getGlobalCredentialStore();
const cred = await globalStore.resolve("anthropic");
```

The daemon uses the core global store; it does not require a separate credential configuration file.
