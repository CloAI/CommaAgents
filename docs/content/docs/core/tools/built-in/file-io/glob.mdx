# glob

Search the workspace for files and folders matching a glob pattern and receive both a structured `matches` array and a human-readable summary. Use this whenever you need to find files or folders by name patterns across the project. Returned paths are workspace-relative and can be passed to `read_file`.

```ts
import { createAgent } from "@comma-agents/core";

const agent = createAgent({
  name: "explorer",
  model: "openai/gpt-4o",
  tools: ["glob"],
});
```

## Usage examples

Match all TypeScript files:

```ts
await tool.glob({ pattern: "**/*.ts" });
```

List immediate children of `src`, including files, directories, and symlinks:

```ts
await tool.glob({ pattern: "*", root: "src" });
```

## Scope and exclusions

`pattern` and `excludeGlobs` are relative to `root`, which defaults to `"."`. Hidden entries are included. By default, `node_modules`, `.git`, `dist`, `build`, `.next`, `.turbo`, and `coverage` are excluded. `excludeGlobs` replaces these defaults; pass `[]` to disable exclusions. `.gitignore` is not consulted. Symlinks are reported without traversing their targets.

```ts
await tool.glob({ pattern: "**/*.ts", root: "src", excludeGlobs: ["**/*.test.ts"] });
```

Entries blocked by `forbiddenGlobs` or by the sandbox read policy are filtered silently. A blocked root returns `permission_denied`.

## Limits and incomplete results

The default caps are 1,000 matches, depth 32, and 256 KiB of returned output. `truncated` and `incompleteReasons` report result limits, traversal limits, and unreadable entries. Cancellation stops the call instead of returning a successful partial result.

```ts
const result = await tool.glob({ pattern: "**/*.ts", maxResults: 100 });
if (result.ok && result.data?.incompleteReasons.length) {
  // Narrow the root or pattern before searching again.
}
```

## Errors

| Kind | When |
|---|---|
| `not_found` | The `root` path is missing or is not a directory. |
| `outside_workspace` | The `root` path escapes the sandbox or absolute paths are disabled. |
| `permission_denied` | The `root` directory itself cannot be read. |
