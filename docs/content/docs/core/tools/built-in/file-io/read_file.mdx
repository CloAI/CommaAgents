# read_file

Read the contents of a workspace file and receive a structured payload with line metadata, a sha256 of the on-disk bytes, and the (optionally sliced) text content. The sha256 is what every later write/edit tool uses to detect stale state — agents should keep it from each read for any file they intend to modify.

```ts
import { createAgent } from "@comma-agents/core";

const agent = createAgent({
  name: "reviewer",
  model: "openai/gpt-4o",
  tools: ["read_file"],
});
```

Binary files return a `binary_file` error. This tool returns text only.

## Line slicing

Pass `startLine` and/or `endLine` (1-indexed, inclusive) to read a window instead of the whole file. Reversed ranges are rejected. `endLine` greater than the file's `lineCount` clamps to the end. A `startLine` past the end of the file returns an empty slice with `truncated: false` — it is not an error.

```ts
// Read lines 50-150 of a long file.
await tool.read_file({ path: "src/server.ts", startLine: 50, endLine: 150 });
```

## Output limit

Files up to 4 MiB are accepted by default, and formatted output is capped at 256 KiB. Oversized slices set `data.truncated` to `true`; request a smaller line range to continue reading. `sha256` always covers the full on-disk bytes, including the original newline encoding and any BOM, regardless of slicing or output truncation.

```ts
await tool.read_file({ path: "src/server.ts", startLine: 151, endLine: 250 });
```

## Errors

| Kind | When |
|---|---|
| `not_found` | The path does not exist or is a directory. Use `glob` with `pattern: "*"` to inspect a directory. |
| `outside_workspace` | The path escapes the sandbox or absolute paths are disabled. |
| `permission_denied` | The path is blocked by `forbiddenGlobs` or sandbox read policy. |
| `binary_file` | The file contains binary content; only text files can be read. |
| `file_too_large` | The file exceeds the configured file-size limit. |
