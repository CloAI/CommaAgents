# createFlow

`createFlow` creates a flow from a name, a set of steps, and an executor function. Use it for one-off branching or dynamic step selection when the built-in sequential, cycle, and broadcast patterns do not fit.

```ts
import { createAgent, createFlow } from "@comma-agents/core";

const classifier = createAgent({
  name: "classifier",
  model: "openai/gpt-4o",
  systemPrompt: "Reply with either technical or creative.",
});
const technicalWriter = createAgent({
  name: "technical-writer",
  model: "openai/gpt-4o",
  systemPrompt: "Write a technical explanation.",
});
const creativeWriter = createAgent({
  name: "creative-writer",
  model: "openai/gpt-4o",
  systemPrompt: "Write an engaging story.",
});

const flow = createFlow({
  name: "routed-writing",
  steps: [classifier, technicalWriter, creativeWriter],
  execute: async (steps, message, flowContext) => {
    const classification = await flowContext.runStep(steps[0]!, message);
    const writer = classification.text.includes("technical")
      ? steps[1]!
      : steps[2]!;
    const result = await flowContext.runStep(writer, message);
    return result.text;
  },
});

const result = await flow.call("Explain monads.");
console.log(result.text);
```

## FlowExecutor

The function that selects and runs steps and returns the flow's final text.

<AutoTypeTable path="../packages/core/src/flows/flow/flow.types.ts" name="FlowExecutor" />

Call `flowContext.runStep()` instead of calling a step directly. Results produced through `runStep()` are included in `FlowResult.stepResults`, contribute to aggregate usage, and participate in step hooks.

```ts
const firstUsefulAnswer = createFlow({
  name: "first-useful-answer",
  steps: [classifier, technicalWriter, creativeWriter],
  execute: async (steps, message, flowContext) => {
    for (const step of steps) {
      const result = await flowContext.runStep(step, message);
      if (result.text.trim().length > 0) return result.text;
    }
    return "No answer was produced.";
  },
});
```

## FlowContext

The step runner and collected results available while the executor is running.

<AutoTypeTable path="../packages/core/src/flows/flow/flow.types.ts" name="FlowContext" />

```ts
const flow = createFlow({
  name: "inspect-progress",
  steps: [technicalWriter, classifier],
  execute: async (steps, message, flowContext) => {
    const draft = await flowContext.runStep(steps[0]!, message);
    console.log(`Completed results: ${flowContext.results.length}`);
    const review = await flowContext.runStep(steps[1]!, draft.text);
    return review.text;
  },
});
```

## Reusable and declarative flows

Use [`buildFlowAgent`](/docs/core/flows/build-flow-agent) when you are implementing a reusable TypeScript flow factory. Use [`defineFlowType`](/docs/core/flows/define-flow-type) and [`registerFlow`](/docs/core/flows/register-flow) when JSON or YAML definitions need to select that implementation by `type`.

```ts
import { buildFlowAgent } from "@comma-agents/core";

const reusable = buildFlowAgent(
  { name: "pipeline", steps: [technicalWriter, creativeWriter] },
  "pipeline",
  {},
  async (steps, message, flowContext) => {
    let currentMessage = message;
    for (const step of steps) {
      const result = await flowContext.runStep(step, currentMessage);
      currentMessage = result.text;
    }
    return currentMessage;
  },
);
```
